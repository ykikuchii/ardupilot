# param-change.lua

## 背景

荷物を積み下ろしするような機体においては、ペイロードの有無によって機体の重量や慣性モーメントが変化し、制御特性が大きく変わります。そのため、ペイロードの着脱に相当するコマンドで同時に制御特性も変更できるようにすることで、ペイロードの有無にかかわらず安定して飛行できるようになります。

このスクリプトは、ペイロードの着脱操作と連動してRCスイッチを操作することで、最適な制御パラメータに自動的に切り替えることを可能にします。

## 概要

`param-change.lua`は、飛行中に制御パラメータ（PIDパラメータ）を安全に切り替えるためのArduPilot Luaスクリプトです。RCスイッチの操作により、2つのプリセット（Preset A/B）間で制御パラメータを切り替えることができます。

### 主な機能

- **RCスイッチによるプリセット切り替え**: RCチャンネル6のPWM値に基づいて、プリセットAまたはBを自動選択
- **安全なI項管理**: パラメータ切り替え時にI項（積分項）を一時的に最小値（0.05）に保持し、その後段階的に目標値までランプアップすることで、急激な変化による不安定化を防止
- **リアルタイム状態表示**: GCSのHUDに現在のプリセットとI項の状態を表示（状態変化時のみ）

### 動作の流れ

1. **即座に適用**: P項、D項などの非I項パラメータは即座に新しい値に切り替え
2. **I項の保持**: I項パラメータを最小値（0.05）に設定し、一定時間（デフォルト500ms）保持
3. **I項のランプアップ**: I項を段階的に目標値まで増加（デフォルト2000ms）

## 依存関係

### 必須要件

- **ArduPilot**: ArduCopter 4.0以降（Luaスクリプティング機能が有効なバージョン）
- **Luaスクリプティング**: 機体のパラメータで`SCR_ENABLE = 1`に設定されている必要があります
- **RC受信機**: RCチャンネル6が利用可能である必要があります（デフォルト設定）

### 使用するArduPilot API

- `rc:get_pwm()`: RCチャンネルのPWM値を取得
- `Parameter()`: パラメータオブジェクトの作成
- `param:set()`: パラメータ値を設定（パラメータシステムに直接反映）
- `gcs:send_text()`: GCSにテキストメッセージを送信
- `millis()`: ミリ秒単位の経過時間を取得

### 対象パラメータ

このスクリプトは以下のパラメータグループを対象としています：

- **ATC_***: Attitude Control（姿勢制御）パラメータ
  - `ATC_RAT_RLL_*`, `ATC_RAT_PIT_*`, `ATC_RAT_YAW_*`: 角速度制御（Rate Control）
  - `ATC_ANG_RLL_*`, `ATC_ANG_PIT_*`, `ATC_ANG_YAW_*`: 角度制御（Angle Control）
- **PSC_***: Position Control（位置制御）パラメータ
  - `PSC_VELXY_*`, `PSC_VELZ_*`: 速度制御
  - `PSC_POSXY_*`, `PSC_POSZ_*`: 位置制御

## 実行手順

## SITLでの確認方法

SITL（Software In The Loop）シミュレーターを使用してスクリプトの動作を確認できます。

### S1. スクリプトの配置（SITL）

SITLでは、実行ディレクトリ（SITLを起動するカレントディレクトリ）に`scripts`ディレクトリを作成し、そこに`param-change.lua`を配置します。

```bash
# SITLを実行するディレクトリでscriptsフォルダを作成
mkdir -p scripts
cp ArduCopter/scripts/param-change.lua scripts/
```

**注意**: SITLを`ArduCopter`ディレクトリから実行する場合、`ArduCopter/scripts`に直接配置するだけで実行されます。ただし、通常はSITLを実行するディレクトリに`scripts`フォルダを作成して配置する方法が推奨されます。

### S2. SITLの起動

ArduCopterのSITLを起動します：

```bash
cd ArduCopter
./waf configure --board sitl
./waf copter
./Tools/autotest/sim_vehicle.py -v ArduCopter -f quad
```

### S3. パラメータの設定（SITL）

SITL起動後、MAVProxyまたはGCSから以下のパラメータを設定：

```
param set SCR_ENABLE 1
param set SCR_HEAP_SIZE 100000
```

### S4. RCチャンネルのシミュレーション

MAVProxyを使用している場合、RCチャンネル6をシミュレートします：

```
# プリセットAを選択（PWM > 1500）
rc 6 1800

# プリセットBを選択（PWM ≤ 1500）
rc 6 1200
```

### S5. 動作確認（SITL）

MAVProxyのコンソールまたはGCSのメッセージウィンドウで、以下のようなメッセージが表示されることを確認：

```
PID PRESET: A (I: HOLD)
PID PRESET: A (I: RAMP)
PID PRESET: A (I: ON)
```

パラメータの変更は、MAVProxyの`param fetch ATC_RAT_RLL_P`コマンドで確認できます。

**注意**: `param show`はキャッシュされた値を表示するため、最新の値を確認するには`param fetch`を使用してください。

## 実機での実行手順

### 1. スクリプトの配置

`param-change.lua`を機体のSDカードの`APM/scripts`ディレクトリに配置します。

```
SDカード/
└── APM/
    └── scripts/
        └── param-change.lua
```

### 2. パラメータの設定

#### 2.1 Luaスクリプティングの有効化

Mission PlannerまたはQGroundControlで以下のパラメータを設定：

- `SCR_ENABLE = 1`（Luaスクリプティングを有効化）
- `SCR_HEAP_SIZE = 100000`（推奨、メモリサイズに応じて調整）

#### 2.2 RCチャンネルの確認

- RCチャンネル6が利用可能であることを確認（デフォルト設定）
- 必要に応じて、スクリプト内の`SW_CH`変数を変更（デフォルト: 6）

### 3. プリセットのカスタマイズ（オプション）

スクリプト内の`PRESET_A`と`PRESET_B`を編集して、機体に最適なパラメータ値を設定します。

```lua
local PRESET_A = {
  ATC_RAT_RLL_P=0.15, ATC_RAT_RLL_I=0.2, ATC_RAT_RLL_D=0.003,
  -- ... その他のパラメータ（SITLデフォルト値）
}

local PRESET_B = {
  ATC_RAT_RLL_P=0.10, ATC_RAT_RLL_I=0.12, ATC_RAT_RLL_D=0.002,
  -- ... その他のパラメータ（重い荷物用）
}
```

**注意**: 変更したいパラメータのみを指定してください。指定されていないパラメータは変更されません。

### 4. タイミングパラメータの調整（オプション）

必要に応じて、以下のタイミングパラメータを調整できます：

- `I_HOLD_MS`: I項を最小値（0.05）に保持する時間（デフォルト: 500ms）
- `I_RAMP_MS`: I項を目標値までランプアップする時間（デフォルト: 2000ms）
- `LOOP_MS`: メインループの実行間隔（デフォルト: 50ms）
- `I_MIN`: I項の最小値（デフォルト: 0.05、PreArmチェックを通過するために必要）

### 5. スクリプトの実行

1. 機体の電源を投入し、ArduPilotを起動
2. SDカードが正しく認識されていることを確認
3. Luaスクリプトが自動的に読み込まれ、実行されます

### 6. 動作確認

#### 6.1 GCSでの確認

GCSのメッセージウィンドウに以下のようなメッセージが表示されます：

```
PID PRESET: A (I: HOLD)
PID PRESET: A (I: RAMP)
PID PRESET: A (I: ON)
```

#### 6.2 RCスイッチでの切り替え

- **PWM > 1500**: プリセットAが選択されます（デフォルト）
- **PWM ≤ 1500**: プリセットBが選択されます

RCチャンネル6のスイッチを操作すると、プリセットが切り替わります（デフォルト設定）。

## カスタマイズ

### RCチャンネルの変更

スクリプトの先頭で`SW_CH`を変更：

```lua
local SW_CH=6  -- チャンネル6を使用する場合
```

### 閾値の変更

プリセット切り替えのPWM閾値を変更：

```lua
local TH=1600  -- 1600以上でプリセットAを選択
```

### プリセットの追加

3つ以上のプリセットが必要な場合は、スクリプトを拡張する必要があります。現在の実装は2つのプリセット（A/B）のみをサポートしています。

## トラブルシューティング

### スクリプトが実行されない

- `SCR_ENABLE = 1`が設定されているか確認
- SDカードが正しくマウントされているか確認
- スクリプトファイルのパスが正しいか確認（`APM/scripts/param-change.lua`）

### パラメータが変更されない

- GCSのメッセージで`"set fail <パラメータ名>"`が表示されていないか確認
- パラメータ名のスペルが正しいか確認
- 機体が対応しているパラメータか確認（一部のパラメータは特定のフライトモードでのみ有効）

### RCスイッチが反応しない

- RCチャンネル6が正しく設定されているか確認（デフォルト設定）
- `SW_CH`の値が正しいか確認（デフォルト: 6）
- RC受信機が正常に動作しているか確認

### パラメータの確認方法

MAVProxyでパラメータを確認する際は、`param fetch`コマンドを使用してください：

```
param fetch ATC_RAT_RLL_P
```

`param show`はキャッシュされた値を表示するため、最新の値を確認するには`param fetch`が必要です。

## 注意事項

- **飛行前のテスト**: 初めて使用する場合は、地上で十分にテストしてから飛行してください
- **パラメータのバックアップ**: スクリプトを使用する前に、現在のパラメータ設定をバックアップしてください
- **I項の管理**: I項を最小値（0.05）に保持する時間が短すぎると、切り替え時に不安定になる可能性があります。また、I項の最小値はPreArmチェックを通過するために0.05以上である必要があります
- **プリセットの調整**: プリセットの値は機体の特性に応じて調整が必要です。自動チューニング機能を使用するか、手動で調整してください
